# extruder-cli

## Purpose

Extruder как исполняемый файл: чем инструмент поставляется, как запускается и что сообщает о себе.
Capability описывает наблюдаемое поведение самого исполняемого файла — опрос, генерация и запись
начальной структуры добавляются последующими изменениями цепочки.

## Requirements

### Requirement: Единственный исполняемый файл

Инструмент SHALL собираться в один исполняемый файл `bin/extruder`, не требующий внешних
зависимостей времени выполнения: ни разделяемых библиотек проекта, ни файлов рядом с бинарником,
ни сетевого доступа.

#### Scenario: Сборка на чистом дереве

- **WHEN** сборка выполнена на дереве без ранее собранных артефактов
- **THEN** появляется исполняемый файл `bin/extruder`, и сборка завершается кодом `0`

#### Scenario: Повторная сборка

- **WHEN** сборка выполнена повторно поверх существующего `bin/extruder`
- **THEN** файл заменяется новым, других артефактов в рабочем дереве не появляется

#### Scenario: Запуск без сети

- **WHEN** собранный `bin/extruder` запущен в окружении без сетевого доступа
- **THEN** запуск не завершается ошибкой обращения к сети

### Requirement: Инструмент сообщает свою версию

Инструмент SHALL печатать строку своей версии в стандартный вывод и завершаться кодом `0`.
Строка версии MUST быть непустой и содержать номер версии в формате `X.Y.Z` с необязательным
суффиксом предрелиза.

#### Scenario: Запуск печатает версию

- **WHEN** `bin/extruder` запущен
- **THEN** в стандартный вывод напечатана строка с номером версии, и код возврата — `0`

#### Scenario: Версия непустая

- **WHEN** строка версии прочитана из вывода
- **THEN** она не пуста и соответствует формату `X.Y.Z` (например `0.0.0-dev`)
