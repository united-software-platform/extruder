## ADDED Requirements

### Requirement: Отказ при разборе профиля не изменяет файловую систему

Разбор профиля и предъявление справки SHALL оставаться операциями, не касающимися диска.
При отказе разбора — недостающем измерении, недопустимом значении, повторе значения — инструмент
MUST NOT создавать, изменять и удалять файлы и каталоги. Изменение файловой системы допускается
только после утверждения записи.

#### Scenario: Отказ разбора не касается диска

- **WHEN** инструмент вызван с ошибочным профилем
- **THEN** состав рабочего каталога после вызова совпадает с составом до вызова

#### Scenario: Справка не касается диска

- **WHEN** пользователь запрашивает справку или вызывает инструмент без единого аргумента
- **THEN** состав рабочего каталога после вызова совпадает с составом до вызова

## REMOVED Requirements

### Requirement: Инструмент не изменяет файловую систему

**Reason**: Требование описывало этап, на котором записи на диск ещё не было: оно предписывало
инструменту ограничиваться разбором и предъявлением профиля. Запись дерева в файловую систему
и есть предмет этапа 3, поэтому запрет целиком перестал быть верным.

**Migration**: Часть требования, сохраняющая силу, перенесена в требование «Отказ при разборе
профиля не изменяет файловую систему» этой же возможности: при отказе разбора и при выдаче справки
диск по-прежнему не затрагивается. Условия, при которых запись допускается, описаны требованиями
возможности `write-approval`: запись идёт в текущий каталог, только после утверждения и только
там, где ни один путь дерева не сталкивается с существующим файлом.
