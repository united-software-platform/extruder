- [x] 4.2 Реализовать вызов точки входа генератора на каждый взятый профиль с отдельным вердиктом

- [x] 4.3 Реализовать проверку трёх свойств вызовом целей `build`, `test`, `lint` оснастки
  сгенерированного проекта с отличимой причиной «цель отсутствует»; проверка — тесты каркаса
  на успешной цели, упавшей цели и отсутствующей цели
- [x] 4.4 Оформить каждый профиль отдельным `t.Run`, добавить вердикты и итоговую сводку

  прогон завершается неуспехом, сводка содержит оба числа
